# Tree texture credits

All photographs/textures are by Poly Haven contributors and are **CC0 1.0**.
They may be modified and redistributed with this game. [Poly Haven license](https://polyhaven.com/license).

- `broadleaf.png`: photographic leaf isolated from the atlas and arranged into a new twig from
  [Tree Small 02](https://polyhaven.com/a/tree_small_02).
- `needles.png`: cropped needle sprig from
  [Pine Tree 01](https://polyhaven.com/a/pine_tree_01).
- `bark.jpg`, `bark-normal.jpg`: [Bark Willow](https://polyhaven.com/a/bark_willow).

Prepared with `tools/fetch_nature.py`: diffuse and opacity combined, foliage cropped to
individual branches, and maps resized for browser use. Tree shapes, branch construction,
canopy placement and wind implementation are original project code in `js/trees.js`.
